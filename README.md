# 🔍 Mini Google

A mini search engine made with Python + Flask.
Search anything and get instant results from Wikipedia!

### ✨ Features
- 🔎 Search anything - Wikipedia results with image + link
- 🔗 Link Shortener - Bada link ku chota kara
- 📱 Simple & Clean UI like Google
- ⚡ Fast & Lightweight

### 🛠️ Tech Used
- Python
- Flask
- HTML / CSS
- Wikipedia API
- DuckDuckGo API
